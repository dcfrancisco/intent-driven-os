# Code of Conduct

OID contributors are expected to foster a welcoming, respectful, and technically rigorous community.

Unacceptable behavior includes harassment, discrimination, intimidation, personal attacks, deliberate disruption, and publishing private information without permission. Critique ideas and code directly, while treating people with respect.

Project maintainers may remove comments, reject contributions, or restrict participation when behavior violates these standards. Report concerns privately to the project maintainers; security concerns belong in the process described in [SECURITY.md](SECURITY.md).
