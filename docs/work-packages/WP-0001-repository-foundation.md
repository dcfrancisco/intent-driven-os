# WP-0001: Repository Foundation

## Purpose

Establish the repository structure, documentation conventions, ownership boundaries, and contribution practices needed for long-term open-source development.

## Scope

Architecture records, work packages, top-level documentation, naming conventions, review expectations, and the initial separation between runtime and console concerns. No runtime, console, or backend code.

## Deliverables

- Repository README describing the Runtime + AI Console vision.
- ADR and WP templates and indexes.
- Documented directory and naming conventions.
- Contribution, review, and decision-lifecycle guidance.
- Initial ownership map for runtime, console, security, and adapters.

## Acceptance Criteria

- A new contributor can locate decisions, work packages, and project boundaries.
- All initial documents use consistent required sections.
- No implementation is introduced as part of this WP.
- Documentation links resolve within the repository.

## Dependencies

None.

## Future Work

Add governance, release, code-of-conduct, licensing, security-reporting, and maintainer succession documents.
