# ADR-0058: MarinaOS GNOME/Wayland desktop foundation

- Status: Accepted for UI foundation
- Related: ADR-0014, ADR-0023, ADR-0053, WP-0116

MarinaOS targets the existing GNOME/Wayland desktop foundation. The first UI
is a user-session client and does not implement a compositor, display server,
login manager, or replacement desktop session. Default-session changes need a
separate accepted ADR.
