# ADR-0063: MarinaOS accessible, offline-first desktop

- Status: Accepted
- Related: ADR-0006, ADR-0036, ADR-0053, WP-0116

The desktop starts without Talvik, renders explicit offline/unavailable states,
uses keyboard-accessible GTK controls and labels, avoids unnecessary polling,
and renders model text as safe plain text. Missing inference cannot prevent
foundation diagnostics.
