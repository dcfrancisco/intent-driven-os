# ADR-0059: MarinaOS GTK 4 and libadwaita UI

- Status: Accepted for initial implementation
- Related: ADR-0002, ADR-0036, ADR-0058, WP-0116

The native desktop uses Rust GTK 4 and libadwaita with shared design tokens,
semantic labels, responsive layouts, and light/dark appearance. The desktop is
Linux-only in this milestone; real graphical-session qualification is required.
